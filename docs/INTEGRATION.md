# 적용 시나리오와 모델 연동

[프로젝트 홈](../README.md)

현재 실행 가능한 대상과 다른 모델에 확장할 때 필요한 작업을 구분해 설명합니다.

## 어디에 사용할 수 있나요?

| 용도 | 이 프로젝트로 할 수 있는 일 | 적용 시 필요한 작업 |
|---|---|---|
| 강성 ODE 솔버 실험 | ode45에서 강성 징후를 감지하고 ode15s 변경 제안·적용 과정을 비교 | 기본 데모로 바로 실행 |
| 감독 정책 프로토타이핑 | 신뢰도 임계값, 자동 적용, 쿨다운, abort 처리 검증 | 설정을 바꾸고 이력 비교 |
| 시뮬레이션 교육·시연 | 제안과 실제 조치의 차이, 상태·수치 건강도 변화 관찰 | 앱 실행 및 발산 주입 |
| 반복 시뮬레이션 분석 | 감독 주기별 결정과 진단을 CSV/MAT로 수집 | 헤드리스 실행을 기존 실험 스크립트에 연결 |
| 다른 MATLAB ODE 모델로 확장 | 모델별 수치 요약을 동일한 질문·정책 인터페이스에 연결 | RHS, 상태 측정, 로그·플롯을 대상 모델에 맞게 수정 |
| 기존 Simulink 모델로 확장 | 시뮬레이션 중 감독 판단을 추가하는 기반으로 사용 | 신호 수집, 실행 제어, 솔버 변경 적용 어댑터 구현 |

현재 mock의 임계값은 데모 검증용입니다. 다른 모델의 물리적 타당성이나 실제 장비의 안전을 검증한 판정기가 아니며, 고속 제어 루프나 하드 실시간 제어를 구현하지 않습니다. 실제 모델에 적용할 때는 해당 모델의 단위·규모·정상 범위에 맞는 요약 지표부터 정의해야 합니다.

## 다른 모델에 적용하기

### MATLAB ODE 모델

현재 실행 루프에는 Van der Pol 전용 측정 코드가 있으므로 **RHS 함수만 교체해서 범용 모델에 바로 적용할 수는 없습니다.** 다음 부분을 함께 수정해야 합니다.

1. [makeDemoPlant.m](../src/makeDemoPlant.m): 대상 모델의 초기 상태와 `sim.rhs(t,x)`를 정의합니다. 솔버, 허용오차, 시간, 중단 상태 등 루프가 사용하는 필드는 유지합니다.
2. [runDemoLoop.m](../src/runDemoLoop.m): `snap.xdot`, `residualNorm`, `energy`, `stiffnessHint`, `notes`를 모델에 맞게 계산합니다. 특히 현재 Jacobian은 Van der Pol 전용입니다.
3. [summarizeSim.m](../src/summarizeSim.m): 대상 모델에서 정상적인 급변과 이상 증가를 구분할 에너지 추세 정의를 검토합니다. 이전 에너지는 `snap.hist(end).energy`로 전달합니다.
4. [appendLog.m](../src/appendLog.m)과 [SupervisorApp_logic.m](../app/SupervisorApp_logic.m): 상태 차원이 두 개가 아니면 x1/x2 기록과 플롯 범례를 조정합니다.
5. 모델 전용 정상·강성·발산 사례를 테스트로 추가합니다. 기존 mock의 응답은 데모용이므로 새 모델의 타당성을 검증하는 정답으로 사용하지 않습니다. 질문 유형과 정규화된 결정 형식은 유지합니다.

이미 별도의 실행 루프가 있다면 플랜트 측정을 `snap` 계약으로 변환한 뒤 `summarizeSim → jevClient → superviseStep`을 감독 경계에서 호출하는 방식으로 재사용할 수 있습니다. `applyAction`은 현재 MATLAB 플랜트 구조체와 cfg를 변경하므로, 외부 시뮬레이터에는 정책 결과를 실제 엔진에 반영할 별도 코드가 필요합니다. 필드 정의는 [CONTRACT.md](CONTRACT.md)를 참고합니다.

현재 데모의 `energy=0.5*(x1^2+x2^2)`는 물리 에너지가 아닌 상태 규모 지표입니다. 이전 값 대비 비율이 50 이상이면 exploding, 1.2 이상이면 rising_fast, 0.95 미만이면 falling, 나머지는 flat입니다. 비유한 상태·에너지도 exploding으로 처리합니다. `residualNorm=norm(f(x))` 역시 실제 적분 오차 추정치가 아닙니다.

### Simulink 모델

현재 저장소에는 실행 가능한 Simulink 예제가 없습니다. `simulink` 폴더가 비어 있어도 MATLAB ODE 데모 실행에는 문제가 없으며, 데모를 위해 파일을 추가할 필요가 없습니다. 연결 시에는 다음 어댑터를 구현해야 합니다.

- 모델 신호·진단을 읽어 `snap` 필드를 만드는 수집 계층.
- 매 제어 스텝 대신 정해진 감독 주기에 판단을 호출하는 실행 계층.
- `policy.simUpdate`를 모델 설정·실행 상태에 반영하는 적용 계층.
- 솔버 변경, 일시 중지·재시작, 상태 보존이 해당 모델에서 가능한지 확인하는 통합 테스트.

MATLAB ODE 청크 사이에서 솔버를 바꾸는 현재 구현과 Simulink 실행 중 설정 변경은 별도의 통합 작업입니다. `.slx` 파일 경로를 `runDemoLoop`에 넘기는 인터페이스는 제공하지 않습니다.
